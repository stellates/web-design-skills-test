# 画面要件テンプレート

Web画面を作成するときは、以下のように簡潔に要件を指定する。

個別の指定がない項目は、以下をデフォルトとする。

- テーマ: Flatly
- レイアウト: お任せ

テーマやレイアウトに希望がある場合だけ、その項目を変更する。

```text
次のWEB画面を作ってください。

- WEBサイト名
  - {サイト名}
- 概要
  - {画面の概要・目的}
- 機能性
  - {必要な機能}
- テーマ
  - Flatly
- レイアウト
  - お任せ
```

## 指定例

テーマだけ変更する場合:

```text
- テーマ
  - Minty
- レイアウト
  - お任せ
```

レイアウトを指定する場合:

```text
- テーマ
  - Flatly
- レイアウト
  - 左サイドバーを使用したダッシュボード構成
```

必要な場合は、`概要` や `機能性` に個別の画面要件を追加する。

デザイン上の細かなルールや実装方針は画面要件へ重複して記載せず、Design Skill側で管理する。
