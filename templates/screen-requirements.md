# 画面要件テンプレート

Web画面を作成するときは、以下のように簡潔に要件を指定する。

個別の指定がない項目は、以下をデフォルトとする。

- テーマ: Flatly
- レイアウト: お任せ

テーマやレイアウトに希望がある場合だけ、その項目を変更する。

```text
次のWEB画面を作ってください。
https://github.com/stellates/web-design-skills-test/blob/main/skills/design_vx.x.x.md

- WEBサイト名
  - {サイト名}
- 概要
  - {画面の概要・目的}
- 機能性
  - {必要な機能}
- テーマ
  - Flatly
- レイアウト
  - お任せ
```

## テーマ指定

テーマはBulmaswatchから選定する。

https://jenil.github.io/bulmaswatch/

指定がない場合は `Flatly` を使用する。

例:

```text
- テーマ
  - Minty
```

```text
- テーマ
  - Darkly
```

```text
- テーマ
  - Lux
```

## レイアウト指定

指定がない場合は `お任せ` とする。

Bulmaで利用できる基本的なレイアウト要素は以下を参考にする。

https://bulma.io/documentation/layout/

Bulmaを利用したページ構成例は以下も参考にできる。

https://bulmatemplates.github.io/bulma-templates/

レイアウトを指定したい場合は、サイトの見た目を丸ごと指定するのではなく、主要な画面構成を簡潔に指定する。

例:

```text
- レイアウト
  - 左サイドバー + 上部ヘッダー + メインコンテンツ
```

```text
- レイアウト
  - 上部ナビゲーション + 1カラム
```

```text
- レイアウト
  - 上部ナビゲーション + 2カラム
```

```text
- レイアウト
  - 左サイドバー + 2カラム
```

```text
- レイアウト
  - ダッシュボード型。上部にKPI、その下にメイン一覧と補助情報
```

```text
- レイアウト
  - 一覧中心。上部に検索・絞り込み、その下にテーブル
```

```text
- レイアウト
  - 詳細画面型。左に主要情報、右に補助情報
```

```text
- レイアウト
  - マスタ・ディテール型。左に一覧、右に選択中の詳細
```

```text
- レイアウト
  - タブ切り替え型。共通ヘッダーの下にタブ、その下に各コンテンツ
```

```text
- レイアウト
  - カードグリッド型
```

```text
- レイアウト
  - フォーム中心。入力項目を縦方向に配置
```

```text
- レイアウト
  - お任せ
```

必要な場合は、`概要` や `機能性` に個別の画面要件を追加する。

デザイン上の細かなルールや実装方針は画面要件へ重複して記載せず、Design Skill側で管理する。

## サンプル

今回の検証で使用した要件を、`design_v1.0.0.md` を指定した形で示す。

```text
次のWEB画面を作ってください。
https://github.com/stellates/web-design-skills-test/blob/main/skills/design_v1.0.0.md

- WEBサイト名
  - Using AI Dashboard
- 概要
  - 利用中AIサービスの稼働状況（障害有無）、最新情報、使用量を見える化するダッシュボード
- 機能性
  - 利用中のAIサービスごとの各種情報が一画面で確認できる
  - リアルタイム同期
- テーマ
  - Flatly
- レイアウト
  - お任せ
```
